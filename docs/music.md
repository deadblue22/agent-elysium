# 背景音乐与音效

## 背景音乐

| 项 | 内容 |
|---|---|
| 曲目 | 用户提供的录音 `public/audio/elysium.mp3`，第四轮之后替换此前的合成曲 |
| 文件 | 原文件 230 秒、256 kbps；去掉末尾约 1.6 秒静音后重新编码为 128 kbps MP3，228.6 秒，约 3.6 MB |
| 音量 | 原文件的整体响度 −15.5 LUFS，播放时乘以 0.11（约 −19 dB），为 −34.7 LUFS（3 秒短时响度中位数 −35.3，最高 −31.3），低于主要音效，见下方「电平」 |
| 循环 | `<audio>` 元素的 `loop`，整首循环 |
| 代码 | `src/audio/music.ts`：`<audio>` 经 `MediaElementSource` 接入 Web Audio，后接低通滤波器与增益 |

播放规则：

- 第一次点击、触摸或按键之后才创建 AudioContext 并开始播放，1.2 秒左右淡入。浏览器会对更早的尝试发出警告，`npm run play` 把控制台警告当作失败。
- 右上角音符按钮开关音乐，选择保存在 `localStorage`（键 `agent-elysium:music`）。关闭后暂停在当前位置，再打开时从该位置继续。
- 标签页隐藏时暂停。
- `?still` 不出声。

剧情联动（`createCues` 的 `onCue` 回调）：

| 指令 | 变化 |
|---|---|
| `flashback` | 低通滤波截止频率降到 1400 Hz，音量降到 0.7 倍，听起来隔了一层 |
| `present` | 恢复 |
| `exit` | 约 10 秒淡出后暂停，并回到开头；结尾之后手动再打开时从头播放 |

调整：音量改 `VOLUME`，回忆时的截止频率与音量改 `COLD`，淡入淡出改 `FADE`。换曲目时替换 `public/audio/elysium.mp3`，或改 `SRC`。

## 音效

全部用 Web Audio 实时合成，不带音频文件（`src/audio/sfx.ts`）。每个音效由几种基本单元组合：带通或低通滤波的噪声、正弦或三角波、带非谐泛音的小铃。每次播放都有少量随机变化，按发生的位置左右声像，经一个小房间混响与限幅器输出。音效用独立的 AudioContext，第一次点击或按键后启用；右上角喇叭按钮单独开关（键 `agent-elysium:sfx`）。

| 音效 | 触发 | 做法 |
|---|---|---|
| 写字 | 日志逐字打出（`LogView.onType`） | 铅笔在纸上划过：每个字两笔，每笔 12–26 毫秒，共振频率在笔画中滑动，笔画之间有短暂抬笔；夹杂几粒石墨颗粒的细响 |
| 继续、悬停、选择 | 点击继续、指针移到可选选项上、选择选项 | 短促的纸面轻响 |
| 骰子 | 掷骰（`CONTACTS` 标出落桌的时刻） | 塑料骰子磕在木桌上：约 1.5 毫秒的高频瞬响，3.8–5.4 kHz 起的四个非谐振动模式在 7–22 毫秒内衰减，每次落面音高不同；落桌后连续弹跳，间隔与音量逐次减小；桌面只有很轻的低频 |
| 检定 | 骰子停下后 | 成功：两声上行的铃；失败：低沉下行的钟声 |
| 内心声音 | 技能说话时 | 一声安静的铃，音高按属性区分（智力、精神、体格、身手） |
| 新线索 | 卡片落下、归档 | 纸片飘落并落在书页上；归档时滑向桌面卡堆 |
| 士气 | HUD 的士气格变化；`?ui=book` 下纸心翻面 | 下降时一段下行短句，回升时上行，从左侧发声；纸心翻面时另有纸的翻动声 |
| 纸片 | 开场、楼梯与狗、马雷克、结尾 | 立起时一阵上扬的纸声与落定；折倒时反向 |
| 场景 | 回忆与结尾 | 窗扇的木头吱呀、风、钟的指针（棘轮）、钟摆（嘀、嗒）、脚步（地板与楼梯不同）、重击书桌、进入与离开回忆的呼啸、点蜡烛与熄蜡烛 |

电平（离线渲染测量）：骰子峰值约 −11 dBFS，重击书桌约 −12 dBFS，写字约 −30 dBFS，其余在 −16 到 −35 dBFS 之间，没有削波。只有开关，没有音量滑块。

音乐与音效的平衡（EBU R128，音效取 400 毫秒瞬时响度的最大值）：

| 声音 | 响度（LUFS） | 与音乐（−34.7）相比 |
|---|---|---|
| 重击书桌、骰子、检定成功与失败 | −24 到 −28 | 高 7–10 LU |
| 士气升降、新线索归档与落下、内心声音 | −32 到 −36 | 大致持平（−1 到 +3 LU） |
| 进入与离开回忆、窗扇与风 | −36.5 到 −38 | 低 2–3 LU |
| 写字（一行）、钟摆、脚步、蜡烛、纸片立起 | −40 到 −44 | 低 6–9 LU |
| 继续、选择、悬停 | −46 到 −47 | 低 11–12 LU，很短的纸声，靠瞬态听见 |

音乐的音量调过两次：第四轮之后用户提供录音时要求稍小一些，从原文件降低约 9 dB（−24.6 LUFS）；第六轮之后用户反馈音乐仍比音效大不少，再降低约 10 dB。当时音乐比骰子与检定还响 1–3 LU，比写字响约 17 LU。
