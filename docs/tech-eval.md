# 技术栈评估：文字与纸面的透视一致性

> 评估对象是 M0 风格板暴露出的问题：左页文字与纸面透视不一致。结论是当前的 CSS 3D 架构在这个问题上没有干净的解法，建议迁移到 Three.js，文字以画布纹理的方式画在页面网格上。

## 1. 问题定义

M0 阶段对文字页尝试了两种实现，各自失败在不同的地方：

| 实现 | 表现 | 失败原因 |
|---|---|---|
| 文字放在 3D 倾斜的页面平面内 | 透视正确，但模糊、被压扁 | 浏览器把带 3D 变换的图层光栅化为位图后再变换，文字以图层分辨率采样；`will-change: transform` 又强制合成，进一步锁死了采样分辨率。倾斜 44° 时垂直方向压缩到六成 |
| 文字作为独立的平面 HTML 层，用投影算出位置贴在页面上 | 清晰，但与纸面脱节 | 文字行是水平的，页面边缘却在收敛；文字不随页面变暗、不受纸纹和光照影响，看起来像印在玻璃上而不是纸上 |

两种做法的矛盾是结构性的：DOM 文字要么进 3D 变换（被光栅化），要么不进（没有透视）。CSS 没有第三条路。

同时暴露的第二个问题：场景的每一层纸片都依赖多组 SVG 滤镜（`feTurbulence`、`feDisplacementMap`、`feDropShadow`）实时计算，在无 GPU 的环境下约 1 帧每秒。层与层之间的投影、纸偶的落地阴影都是手工画上去的，一旦相机角度或光源变化就要重画。

## 2. 需求约束

文字页必须同时满足：

- 清晰：任何相机角度下字形边缘锐利，中文 22px 可读。
- 在纸上：随页面透视收敛，接受页面的明暗与纸纹，与页面一起被翻动。
- 可交互：选项可点击、可悬停高亮。
- 动态：逐字出现、旧行淡化、技能名着色、检定标签加框、光标闪烁。
- 双语：中文断行按字，英文断行按词。

场景必须满足：

- 多层纸片有真实的前后深度与投影。
- 光照可变：窗口冷光、蜡烛暖光、还原动画时切换到夜色。
- 后期：颗粒、暗角、色调。
- 页面翻动、背景板升起、纸偶移动等序列动画。
- 在普通笔记本上稳定 60 帧。

## 3. 候选架构对比

| 架构 | 文字在纸上 | 文字清晰 | 层间真实投影 | 动态光照 | 性能 | 工程量 | 结论 |
|---|---|---|---|---|---|---|---|
| CSS 3D + DOM 文字（当前） | 二选一 | 二选一 | 无，手工画 | 无，手工画 | SVG 滤镜拖慢 | 已有 | 不再推进 |
| CSS 3D + 文字回到页面平面内，2 倍光栅 | 是 | 小倾角下可接受 | 无 | 无 | 同上 | 半天 | 只作为过渡方案 |
| PixiJS + 投影插件 | 是 | 是（画布文字） | 无，2D 假 3D | 有限 | 好 | 中 | 插件维护滞后于主版本，不推荐 |
| Three.js + 画布纹理文字 | 是 | 是 | 是，阴影贴图 | 是 | 好 | 中 | **推荐** |
| Three.js + SDF 文字（troika-three-text） | 是 | 是，任意缩放 | 是 | 是 | 好 | 中偏高 | 段落排版与富文本成本高，可用于少量标签 |
| Unity / Godot 导出 WebGL | 是 | 是 | 是 | 是 | 好 | 高 | 包体大、加载慢、与网页文本和多语言集成差，Demo 阶段不值得 |

参考 demo 的页厚、层间软阴影与背景板升起的方式，符合实时 3D 渲染的特征，而不是 CSS 分层。

## 4. 文字在纸上的四种实现

| 方式 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| DOM 文字进 CSS 3D 平面 | 浏览器光栅化后变换 | 零成本 | 模糊、压扁，Safari 尤其差 |
| DOM 文字平面覆盖 | 投影算位置 | 清晰 | 透视与明暗脱节 |
| 画布纹理 | 用 Canvas 2D 把整页文字画成位图，作为页面网格的贴图 | 任意字体、任意排版、清晰度由画布分辨率决定、自动接受光照与透视 | 断行与富文本要自己排；每次变化重画一页 |
| SDF 文字 | 每个字形生成有向距离场，着色器渲染 | 任意缩放下锐利、内存小 | 中文按需生成字形，段落排版、加框、混排颜色需要多个对象拼装 |

画布纹理是最贴合需求的：文字页本来就是「一张纸上的一整版内容」，作为一张贴图处理最自然。页面尺寸约 670 × 600 屏幕像素，画布以 2 倍设备像素比绘制即 1340 × 1200，开启各向异性过滤与 mipmap 后，倾斜角度下不会闪烁。中文断行按字、避免行首标点，英文按词，几十行排版代码即可。

## 5. 推荐架构

```
Vite + TypeScript
├── three            场景、材质、光照、阴影、后期
├── scene/
│   ├── table.ts     木桌平面，纹理 + 法线
│   ├── book.ts      封面、页叠、左右页网格（页面带轻微弧度）
│   ├── popup.ts     背景板各层：PlaneGeometry + 带透明通道的纸片纹理，绕折缝铰接
│   ├── puppets.ts   纸偶：同样是铰接的纸片平面，可换姿势贴图
│   ├── lights.ts    环境光 + 窗口方向光（冷）+ 蜡烛点光（暖），阴影贴图
│   └── post.ts      颗粒、暗角、色调的一个自定义着色器通道
├── page/
│   ├── layout.ts    日志排版：中英断行、缩进、行距、着色、加框
│   ├── painter.ts   Canvas 2D 绘制，输出 CanvasTexture
│   └── hit.ts       射线命中页面 → UV → 行框 → 选项索引
├── engine/          对话树、检定、骰子、旗标（与 design.md 第 7 节一致，不变）
└── assets/
    ├── art/*.svg    纸片的矢量源文件
    └── textures/    构建时由 SVG 栅格化的 PNG（带透明通道）
```

关键决定：

- **纸片纹理离线烘焙。** 撕边、纸纹、污渍在 SVG 源文件里做一次，构建脚本栅格化成 PNG。运行时不再执行任何 SVG 滤镜。
- **投影与光照交给渲染器。** 层间投影、纸偶落地阴影、蜡烛的暖光衰减全部由阴影贴图与光源产生。改相机、改光源不需要重画任何素材。
- **文字页是一张贴图。** 排版器把当前节点的日志画到画布，贴到左页网格。逐字出现只是每帧多画几个字。旧行淡化、技能名着色、检定标签加框都在画布里完成。
- **交互用射线。** 指针事件转成射线，命中左页网格后取 UV，查排版器输出的行框，得到选项索引。悬停高亮重画该行。
- **后期一个通道。** 颗粒、暗角、色调在一个片元着色器里完成，成本固定。

## 6. 迁移计划

| 阶段 | 内容 | 工作量 |
|---|---|---|
| 验证 | 木桌、书本、一张带画布文字的左页、两层纸片、一个纸偶、两盏灯、后期通道。目标只有一个：确认文字既清晰又在纸上 | 1 到 2 天 |
| 迁移素材 | 把 M0 页面内的 SVG 纸片抽成独立文件，去掉运行时滤镜，烘焙成 PNG | 1 到 2 天 |
| 文字页 | 排版器、绘制器、射线命中、逐字动画 | 2 天 |
| 场景动效 | 背景板升起、视差、雪、翻页、还原动画的四段序列 | 2 到 3 天 |
| 引擎 | 对话树、检定、骰子、旗标、语言切换（M1 原计划） | 3 到 4 天 |

M0 已完成的部分中可以直接复用的：全部 SVG 纸片造型、配色、字体子集、排版规则、剧本。作废的只有 CSS 3D 的布局代码。

## 7. 风险

| 风险 | 应对 |
|---|---|
| 画布文字在斜视角下闪烁 | 2 倍分辨率、mipmap、各向异性过滤设为设备最大值 |
| 中文字体加载前画布绘制出回退字体 | 用 FontFace API 等待字体就绪后再首次绘制 |
| 无 WebGL 的环境 | 检测后显示静态截图与提示，Demo 不做降级渲染 |
| 三维场景在移动端发热 | 层数少、贴图总量控制在 20 MB 内、后期只有一个通道 |
| 无障碍 | 日志同时输出到一个隐藏的 DOM 列表，供读屏 |

## 8. 过渡选项

如果暂时不迁移，最小代价的修补是把文字放回 CSS 3D 页面平面内，去掉 `will-change`，在平面内以 2 倍尺寸渲染再缩放，并在同一平面上叠一层正片叠底的明暗渐变。倾角保持 22° 以内时，压缩约 7%，可读。这条路解决「脱节」，但不解决 SVG 滤镜的性能、层间投影与光照的手工维护，也不解决 Safari 的模糊。只适合作为等待迁移期间的临时版本。
